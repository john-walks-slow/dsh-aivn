# aivn-play-setup（备料流程与各文件写法）

用户要开新剧目、或要改现有剧目的设定时，按下面四步走，**不要跳步**。

## 一、四步流程

1. **先问清再动手**：一轮里问 3~5 个问题就把骨架定下来——故事类型与基调、时代与地点、主角是谁、
   主角想要什么 / 被什么困住、核心角色 1~2 位、画风与文风、**节奏（想让人物一口气演一段，
   还是每轮都给玩家选择）**。**每个问题都带上你的具体默认提案**（用户点一下「就按你说的来」
   就能继续），别让人从零填空。
2. **给完整提案再落盘**：把理解成的 premise（3~6 句）、角色卡、创作口径、写作参数、还缺哪些素材
   一次性摆给用户看，等一句「可以 / 就这样」再落盘。开着命令行的话，`grep` / `jq` 这类比整篇读快得多。
3. **列图单、出候选、拿到点头再入库**：先说清「接下来要出这几张图：背景 A（什么场景）、
   立绘 `<主体id>/neutral`、…，各是什么画面、为什么要」。
   - 配了生图工具：先 `generate_image` 出候选（同一目标多调几次），把预览贴给用户挑，**用户点头之后**
     才落位——背景/插图 `import_asset(name=…, kind=…)`、立绘 `cut` 后 `import_asset(kind="sprite", …)`；
     或者干脆用 `generate_asset(kind=…, …)` 一键出图入库（常规补素材走这条）。出图要钱也要时间，
     别一口气出一堆；定妆照（neutral）一次出 3 张候选让用户挑。
   - 没有生图工具：把图单交给用户，让他自己放进 `assets/`；放进来之后你用 `import_asset` 登记（立绘先 `cut` 抠底）。
4. **落盘后同步记忆**：premise 写进 `memory/always/premise.md`，**创作口径写进 `memory/always/craft.md`**、
   **写作参数用 edit 写进 `play.json` 的 `craft` 段**，素材的描述补进 `assets/manifest.json`。
   不是只在对话里说一句。

## 二、各文件写什么

**世界观前提（`memory/always/premise.md`）**：3~6 句。写清这是什么世界、玩家扮演谁、
他想要什么、被什么困住。这是剧作家每一轮都要读的唯一真相源，含糊一句它就要自己编。

**创作口径（`memory/always/craft.md`）**：散文口径——文风、人称与称呼习惯、禁忌、这个剧目
特有的约定。**只装「用话说得清」的部分**：能结构化的（每轮篇幅、停止点选项数）写进 `play.json`
的 `craft` 段，不要两边都写一遍。画风锚点也写在这里（怎么定见技能 `aivn-visual-craft`）。

**写作参数（`play.json` 的 `craft` 段）**：用 `edit` 定点改这一个键，文件里其余字段一个字节都别动。
不写某一项 = 走引擎默认（默认值日后改了它跟着改），要钉死就写进去。取值只认这几个
（**以每轮注入的《写作参数》为准**，这里只是速查）：

| 键 | 认的值 | 是什么 |
|---|---|---|
| `beatLength` | `short` / `medium` / `long` | 一轮写多长 |
| `stopOptions` | `two` / `three` / `four` / `free` | 停止点给几条选项 |
| `assets.background` | `library-first` / `library` / `generate` | 背景从哪来 |
| `assets.cg` | `library` / `generate` / `off` | 插图从哪来 |
| `assets.sprite` | `generate` / `off` | 立绘从哪来 |
| `assets.audio` | `library` / `off` | 音乐音效从哪来 |

`library` / `library-first` 那两个值本插件没有对应能力（没有跨剧目素材库），写了等于没写。
写错的值引擎**静默当没写**——写完拿 `validate_play` 核一遍。

**角色卡（`characters/<id>.md`）**：格式见《剧目文件》；内容上只写「这个人在戏里怎么动」——
年龄、身份、关系、说话方式、在意什么。要维持年龄段气质时在正文加一节「外形」，把**头身比**
（萌系 5~5.5、标准高中生 6~6.5）与发色 / 瞳色 / 发饰 / 服装逐件钉死（细节见技能 `aivn-visual-craft`）。
玩家扮演的主角 id 固定 `protagonist`。

**设定记忆卡（`memory/index/<层>/<名字>.md`）**：首行 `# 标题`，第二行一句话摘要（剧作家只读得到
这一行），其余写详情。层（子目录）是自定的分组，比如 `world` / `cast` / `items`。

** `play.json`**：字段表见《剧目文件》。写作参数那一格（`craft`）用 edit 定点改。

**素材描述表（`assets/manifest.json`）**：键是素材 id（立绘差分写成 `<主体id>/<差分名>`），
值是描述。别删别人写的键，也别把整张表重写一遍——它有两个写者（你与用户）。

**音色**：角色卡 frontmatter 的 `voice` 填 Fish 音色 id。有 `list_voices` 就**别凭记忆编**——
按 language / tags / query 收窄、按人设挑那个嗓子，把选中的 id 写进卡里；没有这个工具就留空，别编。

## 三、备料顺序

先把 premise 与主角卡写出来，再补配角与设定卡，最后配素材与音色。用户拿着半座剧目也能开演，
但前提空着他什么都写不出来。
